# Publication Strategy

## Internal Source of Truth

- `manuscript/master_manuscript.md`

## Derived Versions

- `manuscript/neurips/core_version.md`
- `manuscript/jmlr/flagship_version.md`
- `manuscript/nature_mi/impact_version.md`
- `manuscript/focm/companion_version.md`

## Rules

- NeurIPS version only contains the architectural core, theorem statement, and decisive experiments.
- JMLR version carries the full benchmark suite, ablations, reproducibility, and machine-proof companion.
- Nature MI version is only viable if the benchmark story is broad and dominant.
- FoCM version must stand as a theorem-centric mathematical companion, not as a recycled appendix.
